Every government calls it "voluntary."
The reporting record says otherwise, some of the time, in some places, by a lot.

The Coercion Gap Index measures the distance between the language states use for refugee return and the material conditions on record — using return volumes, deportation shares, conflict exposure, and a hand-coded 100-phrase lexicon of official vocabulary. Nothing below is invented: every number is pulled from the cited UNHCR-IOM, EUAA/ACLED, ACCORD, WHO, or Reuters/UN source inside the underlying workbook.

On completeness: the workbook's full Coercion Gap Index averages four sub-scores. Forced Return Score, Return Spike Score, and Arrest Pressure Score are deterministic and computed here exactly from the raw data. The fourth, Policy Pressure Score, is a qualitative 5–9 judgment call hand-coded per row in the source file; its exact values could not be recovered from the workbook and are omitted rather than estimated. Read the line above as a partial index.

Humanitarian
Presents return as protective, rights-based, or dignified.

Burden / Capacity

Kinship
